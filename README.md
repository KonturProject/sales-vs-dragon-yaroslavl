# Победи дракона — Ярославль

Игра-табло для офисного экрана: герои восьми групп филиала (ЕСЦ1…ЕСЦ8) бьют пятиглавого дракона, каждый раз когда у группы прибавляются оплаты. **Игра дневная**: каждый рабочий день — новый дракон и свой план; пятая часть дневного плана — одна голова, весь план — победа. **Считаются штуки оплат, а не деньги**: на экране «14 / 40 оплат сегодня».

Днём руководители групп (РГ) вносят платёжки на своей странице — герой группы сразу бьёт дракона. Утром следующего дня, после разноса оплат по счетам (к 11:30), админ загружает выгрузку CRM за вчера: она решает итог вчерашнего дня, и экраны объявляют его — «Вчерашний дракон пал!» или «Вчера срублено 4 из 5 голов — сегодня добьём!». Сегодняшний бой при этом идёт своими платёжками.

Это ответвление ульяновской версии [«Победи дракона»](https://github.com/KonturProject/sales-vs-dragon-ulyanovsk) (та — недельная, шесть групп и лидер филиала).

- Игра: https://konturproject.github.io/sales-vs-dragon-yaroslavl/
- Админка (PIN): https://konturproject.github.io/sales-vs-dragon-yaroslavl/admin.html
- Оплаты группы — страница для РГ (свой PIN у каждого): https://konturproject.github.io/sales-vs-dragon-yaroslavl/rg.html

## Что умеет админка

- **План** — сетка рабочих дней этой и следующей недели: у каждого дня своё число оплат; день без своего плана берёт план последнего рабочего дня до него. Галочка «выходной» — праздник (экраны показывают «Выходной», РГ не вносят). Суббота и воскресенье — всегда выходные.
- **Таблица** — последние строки таблицы оплат и итог сегодняшнего дня.
- **Внести оплату** — тот же счётчик, что у РГ, для любой группы и любого рабочего дня до сегодня.
- **Импорт** выгрузки «Детальные данные по оплаченным счетам» (.xlsx разбирается в браузере; один счёт — одна оплата, счета дешевле 100 ₽ не считаются; заменяет оплаты за период файла). Если период включает последний рабочий день — экраны объявляют его итог.
- **Герои** — кто стоит за каждую группу (30 персонажей) и **ФИО РГ** на табличках «ЕСЦ1 • Фамилия И.» (полное ФИО сокращается само).
- **Анимации** — удар, падение, рычание, конфетти, «Показать итог вчерашнего дня».
- **PIN-код** — смена PIN админки и PIN-коды РГ (создаются случайно, показываются один раз).

## Страница руководителей групп

`rg.html` — одна функция: сколько оплат у своей группы **сегодня**. Группу страница узнаёт по PIN. «−» / «+» и «Сохранить · было 2, станет 3»; если число выросло — герой группы бьёт дракона. Прошлые дни РГ не меняют (их итог решает утренняя выгрузка), в выходной внести нельзя.

## Группы

В таблице (лист `Sales`, колонка `ROP`) — короткие коды `ЕСЦ1`…`ЕСЦ8`. Полные названия из CRM понимаются по части «ЕСЦ<число>» (а также «ESC<число>» латиницей) — `game/src/game/config/ropMapping.json`, `game/src/game/systems/Groups.ts`.

## Команды

Из папки `game/`:

```bash
npm install
npm run dev                 # локально, http://localhost:8080
npm run build               # сборка в game/dist
npm run deploy              # сборка + публикация на GitHub Pages
npm run test:backend        # тесты Code.gs на имитации сервисов Google
npm run mock-backend        # Code.gs локально на :8787 (PIN 1234); игру/админку направить: ?backend=http://localhost:8787/exec
npx tsc --noEmit -p tsconfig.json
```

## Бэкенд

Google Apps Script + таблица «победи дракона Ярославль» — см. [apps-script/README.md](apps-script/README.md). PIN админки хранится только в свойствах скрипта (хеш), в репозитории его нет.
